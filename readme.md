# Game assistant for Windows

## Project description

This is a console app for Windows which will monitor the selected game via screen capture and graphics patterns search. It will also automate some predefined actions using key press and mouse click emulation. These predefined actions will depend on game status determined by game screen monitoring.

In general (in furture versions) this app will be able to work with any directx game for Windows. For the begining it will be written for EVE Online.

## Some implementation detailes

For the sake of performance the project will be written in C++ standard 17 and all predefined actions will be hardcoded.
